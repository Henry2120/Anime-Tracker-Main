# AniVerse Music Lab — External Character Directory (Aria)

Place the external customized VRM character asset here:
- `public/music-lab/characters/aria/aria.vrm`
- Or `public/music-lab/characters/aria/aria.glb` (fallback)

## Specification:
- Format: VRM 0.0 or VRM 1.0 (recommended)
- Humanoid Skeleton standard
- Spring bone physics for hair and skirt
- BlendShapes / Expressions: `blink`, `happy`, `relaxed`, `neutral`, `aa` (singing)
- Zero instrument baked into mesh or skeleton (instruments are dynamically attached in AniVerse)
